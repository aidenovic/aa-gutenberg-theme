# AA Gutenberg Theme

Version 1.1.1 · eigenständiges WordPress-Block-Theme · GPL-2.0-or-later.
WordPress ab 6.6, PHP ab 8.0; geprüft mit WordPress 7.1.3 und PHP 8.3.

Ordner und Text Domain: `aa-gutenberg-theme`. Dieses Theme benötigt kein Parent,
ACF oder Gutenberg-Plugin. Es liefert eine neutrale Systemschrift-Gestaltung,
native Blockvorlagen, bearbeitbare Header/Footer, globale Stile und einen
optionalen dynamischen Kontaktblock. Keine externen Fonts, Tracker oder Logos.

Die Aktivierung legt keine Inhalte an. Unter **AA Gutenberg Theme → Einrichten**
kann ausdrücklich eine Starterseite als Entwurf angelegt werden. Wiederholtes
Einrichten öffnet dieselbe Seite und überschreibt keine bearbeiteten Inhalte.
Die Startseitenzuordnung wird ausschließlich in WordPress unter Lesen geändert.
