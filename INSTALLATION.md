# Installation

1. In einer von dir ausgewählten WordPress-Installation **Design → Themes →
   Theme hinzufügen → Theme hochladen** öffnen.
2. `aa-gutenberg-theme-1.1.0.zip` hochladen. Im ZIP liegt genau ein Theme-Ordner
   `aa-gutenberg-theme/`. Das ZW-Theme wird nicht ersetzt und wird nicht benötigt.
3. Zunächst die Vorschau prüfen, dann das AA-Theme bewusst aktivieren.
4. **AA Gutenberg Theme → Einrichten** öffnen. Optional die Starterseite als
   Entwurf erstellen, eigene Inhalte eintragen und anschließend veröffentlichen.
5. Falls gewünscht unter **Einstellungen → Lesen** diese veröffentlichte Seite
   als statische Startseite zuordnen. AA führt diese Änderung nicht selbst aus.
6. Unter **Design → Editor** Logo, Header, Navigation, Footer und Stile bearbeiten.
   Vorhandene Daten deiner Installation können im Website-Namen und Logo
   erscheinen; AA bringt keine eigene Logo-Grafik mit.

Alternativ den Theme-Ordner nach `wp-content/themes/aa-gutenberg-theme/` kopieren.
Nur den Theme-Ordner übertragen, nicht die gesamte Entwicklungsablage.

Bei einer vorhandenen Installation vor dem Themewechsel Inhalte und Datenbank
sichern und die Darstellung prüfen. Seitentexte, Medien und vorhandene Seiten
bleiben erhalten; bisherige Theme-Templates oder eigene Blöcke sind nicht
automatisch mit AA kompatibel. Es gibt keine ZW-/ACF-Inhaltsmigration.

Gespeicherte AA-Templates und Global Styles haben Vorrang vor Theme-Dateien.
Beim Update werden sie nicht zurückgesetzt. Im Site Editor gespeicherte Änderungen
über dessen Exportfunktion übertragen; Seiten, Medien und Plugin-Daten separat
exportieren. Ein Theme-ZIP enthält keine WordPress-Installation oder Datenbank.

In diesem Auftrag wurde das Theme ausschließlich vorbereitet und geprüft.
Es wurde auf keiner bestehenden Website installiert oder aktiviert; keine neue
Domain, Serverkonfiguration, Datenbank oder Benutzerkonten wurden eingerichtet.
